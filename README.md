
# ShopEase — Shopping Cart Application

## Project Overview
A responsive shopping cart application built as part of the
Codenzic Innovations React JS Developer / Intern assignment.

## Technologies Used
- React 19
- TypeScript
- Vite
- Bootstrap
- Zustand
- TanStack Query
- Zod
- localStorage
- pnpm

## Features
- Product listing from DummyJSON
- Product search and category/price filtering
- Cart management and quantity limits
- Cart persistence using localStorage
- Tax and discount calculations
- Three-step checkout
- Zod shipping form validation
- Responsive interface

## API
https://dummyjson.com/products

## Setup Instructions
1. Install Node.js and pnpm.
2. Clone this repository.
3. Run `pnpm install`.
4. Run `pnpm dev`.
5. Open the local URL shown in the terminal.

## Build
Run `pnpm build` to create a production build.

## Known Limitations
- Demo checkout only; no real payment gateway.
- Orders are not submitted to a backend.
